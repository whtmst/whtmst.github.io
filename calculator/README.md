# WM Calculator

A lightweight, purely client-side web tool for converting project tempo (BPM) into note durations in milliseconds and hertz.

This tool was created primarily for personal studio workflow - setting delay times, compressor attack/release starting points, LFO rates, and other tempo-synced values without opening a DAW or hunting through plugin menus.

## Features & Technologies

* **BPM → ms / Hz:** Enter any tempo and get note lengths for 1 bar through 1/64, with values in both milliseconds and hertz.
* **Straight / Triplet / Dotted:** Switch note grids instantly; 1 bar always stays four straight quarter notes.
* **Copy on click:** Click any ms or Hz value to copy it to the clipboard for pasting into a plugin or DAW.
* **Client-Side Only:** All calculations run in the browser. No accounts, no uploads, no network requests for the math.
* **Hub embed:** Designed to open inside the WHT MST hub as a module (iframe + height reporting), and also works as a standalone page.
